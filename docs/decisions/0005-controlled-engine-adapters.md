# ADR-0005 代理核心适配器 + 已有服务只读发现

- 状态：Accepted as design baseline
- 日期：2026-10-29

## 决策

不自行实现代理转发协议。Agent 通过类型化 Engine 适配 sing-box、Xray、Realm。能力按引擎版本探测，不假设支持热更新。已存在的外部服务默认只读观察，用户确认接管后才能由 Viorka 管理。

## 理由

降低配置破坏风险，适配版本差异，也适用于单节点多服务、NAT 端口受限情形。

## 2026-11-03 首批交付约束

[节点、引擎与服务开发设计](../ENGINE_SERVICES.md) 明确每节点每种引擎最多一个托管实例，允许三种引擎共存；第三方实例只读发现，同类存在时阻止安装，不在首版提供接管。发布与恢复以引擎为单位，运行意愿独立于配置应用；已成功更换的旧凭证不得通过历史恢复重新启用。交付顺序为 sing-box、Xray、Realm TCP，以上仍为设计而非已实现能力。
