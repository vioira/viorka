# 公开节点状态页

每个 Panel 提供一个访客入口 `/status`，新安装和升级后默认关闭。管理员在「系统设置 → 公开状态页」勾选节点、编辑公开别名及展示顺序，然后预览并发布。新注册的节点需要单独选入。发布后可以复制链接、立即撤下单个节点，或关闭整页。后台预览只对管理员可见。

## 节点分组和标签

在「节点 → 管理节点分类」建立分组或标签。每个节点至多属于一个分组，可以有多个标签。管理员可在列表内批量调整归属，也可以在节点详情编辑分类。重命名保留成员，删除分类会解除该分类的所有关联。分类默认仅在后台可见，勾选「在公开节点上展示此分类」后，其名称才出现在所选节点的公开卡片上。

后台节点列表支持按分组和标签筛选。公开页按分组和国家或地区筛选，显示各地区节点数，支持按管理员顺序、名称、带宽或到期时间排序。四项汇总和续费提醒均按当前筛选范围计算。

## 访客可见的数据

| 项目 | 口径 |
| --- | --- |
| 在线节点 | Agent 管理连接在线的节点数及筛选范围内的节点总数。资源采样另有时间戳。 |
| 实时带宽 | 有新鲜双向读数的节点上、下行速率之和，单位 B/s。缺少读数时展示覆盖数量。 |
| 累计流量 | 汇总 Panel 已保存的日流量账本，分列入站与出站。跨账期连续累计，重注册日期重叠时沿用现有账本的取舍规则。卡片给出最早记录日和缺口标记。 |
| 资产概览 | 将登记的周期价格按剩余租期折算为人民币。每个周期按到期日回推对应的日历月数。已过期或明确免费的节点估值为零，缺少估值字段或汇率的节点显示为未计入。续费提醒列出已到期和未来七天内到期的节点。 |
| 节点资源 | 展示国家或地区（含近似省市）、节点类型、架构、操作系统、观测到的公网地址族、CPU、内存与 Swap、磁盘容量与磁盘 IO、1/5/15 分钟负载、连接数和进程数。CPU 核数由管理员在发布配置中选填。 |
| 网络与租用 | 展示上行、下行、近期速率、今日与出入站累计、本期起点/已用/剩余额度、已配置 TCP 线路的延迟与连接失败率、主机上报的运行时长、最后在线时间、到期日、租用周期和价格。额度按已应用的单向或双向计费模式计算。 |

节点卡片展示快照时间之前最近 20 个已结束的 3 分钟区间。每条线路的色块展示该区间内最近一次采样的延迟和失败率。整个区间都没有采样时显示灰点。线路旁的数值显示最新观测。

线路以配置的展示名称标识，未命名时显示「线路 1」等序号。公开接口只提供地址族和线路观测。IP 地址、原始探测目标、网卡清单及私有分类保留在管理端。节点未采集的字段显示未知，探测全部失败时保留失败率。

## 历史与刷新

在公开页点击节点名可以查看最近 1 小时、6 小时、24 小时、2 天或 7 天的资源、带宽和线路趋势。资源历史返回与节点详情指标页同源的 8 组曲线（CPU、内存、网络、连接数、负载、文件系统容量、磁盘 IO、进程数），使用保留期内已有的节点记录，包含首次发布前和两次发布之间的样本。缺少观测的区间显示缺口。撤下节点后，后续匿名请求无法读取其详情数据或历史，重新发布后按当时保留的数据展示。

详情页的 TCP 历史色块覆盖所选查询区间，首尾区间按返回时间裁剪。历史尚未取得时，线路区域显示标明时长的一小时快照。

公开快照的 `fast.expires_at` 和 `full.expires_at` 分别表示快速和完整采样的有效截止时间。带宽按方向展示有效读数，管理连接离线时仍可读取新鲜采样。

公开页复用 Panel 已接收的采样。启用系统实时推送时，访客通过独立的公开 SSE 连接接收快照；管理员关闭推送后，访客仍可使用「刷新状态」。访客访问不向 Agent 申请实时采样租约。公开快照共享五秒缓存，读取时校验发布和分类版本。资源历史最多返回每条曲线 120 个时间桶。

## 汇率

需要折算外币时，Panel 按 UTC 日期读取并持久化当日美元基准报价。同一实例并发读取共用一次刷新，重启后沿用当日缓存。获取失败时优先使用上一次报价，十五分钟后再尝试。页面展示参与折算的实际报价日期，包括周末沿用的上一交易日报价。[Frankfurter 汇率接口](https://api.frankfurter.dev/v2/rates?base=USD)

## 接口与并发编辑

| 路径（相对于 `/api/v1`） | 访问 |
| --- | --- |
| `GET /status`、`GET /status/events` | 匿名快照与 SSE。关闭后快照返回 404，正在推送的连接收到撤回事件。 |
| `GET /status/nodes/{id}/history?range=7d` | 仅限当前公开节点，支持 `1h`、`6h`、`24h`、`2d`、`7d`。 |
| `GET/PUT /settings/status-page`、`POST /settings/status-page/preview` | 管理员读取、发布或预览配置。最多公开 128 个节点。 |
| `GET/PUT /node-categories`、`PATCH /node-categories/members` | 已登录用户可读取目录，管理员可编辑和分配。目录最多 256 项，每批最多 256 个节点。 |

发布配置和分类目录分别使用版本号。多人提交旧版本时返回 409，重新读取后可按最新配置修改。撤回控制后续访问，访客此前已经取得的数据仍可能留在其设备上。
