# VLESS 协议预设

协议配置是实例范围内共享的非敏感参数。创建只保存记录与审计；编辑保存前必须预览并确认影响范围。已发布服务持续继承协议参数，有效配置变化时自动更新对应节点引擎的目标配置。协议配置本身没有同步版本，不生成 UUID 或 REALITY 私钥。

## 当前能力

- “协议配置”菜单提供分页列表、新建与编辑页面，名称唯一。
- 仅 VLESS；可保存 XHTTP / TCP (RAW + Vision) / WebSocket、REALITY / TLS、站点目标、SNI、Short ID、客户端指纹、源站证书、CDN 主机名及传输路径。
- TCP 仅可搭配 REALITY，WebSocket 仅可搭配 TLS；自签名源站证书须指定 CDN 主机名。
- Short ID 支持最多 8 个不重复的偶数位十六进制值，每项 2 至 16 位。REALITY 留空时由服务端在保存预设时自动生成两个不同的 16 位十六进制值，并持久化、通过创建和列表响应返回。用户手动填写的值保持不变；前端忽略空白条目，TLS 不生成 Short ID。
- 新建页提供非敏感参数摘要。预设没有节点对外地址、UUID 或公钥，不生成可用连接链接，也不宣称订阅格式兼容性。

## 节点引用

当前执行链路仅支持 TCP + REALITY、外部握手目标、Chrome 指纹及有效 Short ID。添加服务时自动读取协议配置，以 Arc 下拉框选择引用；默认继承名称、端口、SNI、握手目标及目标端口，不再重复填写协议参数。端口与 SNI 可留空沿用配置或填写节点覆盖值；服务名称、监听 IP 和对外入口放在可选节点参数中。加入本地草稿、保存共享草稿后，仍须单独应用配置。

引用记录 `preset_id`，并显式保存可选的 `port_override` / `sni_override`。未设置表示持续继承，显式设置即使等于默认值也保持独立；清空恢复继承。服务名称、监听 IP、对外入口及启用状态属于节点参数。读取、保存草稿和手动应用都会重新解析继承参数；首次部署仍需单独应用草稿。

协议编辑只更新已提交发布目标中的引用服务，不自动发布未应用草稿的新增、删除、覆盖或启用修改。应用时服务复用协议中的全部 Short ID，UUID 与 REALITY 私钥保持服务独立。导出的单条客户端连接链接使用列表中的第一个 Short ID，其余值同样被引擎接受。编辑时 Short ID 全部留空保留当前列表，创建时留空仍生成两个值。Realm 拒绝 VLESS 引用；不兼容配置或端口冲突显示同步失败，不能宣称部署成功。

## 自动同步

- 按“节点 + 引擎”合并完整有效配置，与最新目标比较。比较忽略配置版本字段及服务排列顺序；管理名称和被节点覆盖的默认值变化不推进目标版本。每次保存每个变化引擎只增加一次版本。
- 预览包含字段前后值、引用节点在线状态、服务及独立覆盖、同引擎全部服务、运行意愿及校验问题。`base_digest` 只用于编辑并发检查，`confirmation` 是绑定当前用户、配置和影响范围的服务端 MAC，不是协议版本。确认过期返回 409，保留表单与弹框，通过全局 Toast 提示。
- 保存事务原子更新协议、目标快照、引擎期望修订及审计。离线节点只持久化目标，不创建任务；离线连续修改后只保留最新待同步目标。
- 鉴权且具备 `engine.manage.v2` 的在线 Gateway 每秒检查目标版本与已持久化的 Agent 确认版本。需要执行时才创建 `engine.apply` 任务，并冻结该次执行快照。各节点独立同步，同引擎串行，节点派发也受当前任务租约限制。
- 已开始执行的旧版本不会被改写；其成功只推进对应已确认版本，下一轮继续应用最新目标。未派发的自动任务可以合并为新目标。已授权手动任务及执行中断线的任务保留执行记录与现有幂等重投语义。
- Agent 回报成功才更新已确认版本、连接参数和凭证快照。运行中的引擎按实际适配器重载/重启；手动停止的引擎保持停止。旧端口仅在确认成功后释放，并继续保护未发布草稿与更新目标的端口。
- 网络重投沿用同一任务的租约和次数上限。配置失败不无限创建新任务；用户处理后可重试目标，或再次修改配置生成新目标。执行超时/结果未知先核对引擎，禁止盲目重发。恢复上一配置仍使用当前共享协议参数及有效凭证，不回滚实例共享配置。当前握手没有新增实际版本报告字段；对账使用 Panel 保存的已确认版本及现有任务回执，不声称能自动修复 Agent 本地状态文件丢失。
- 节点 API 暴露 `sync_state`（unpublished/pending/syncing/synced/failed）及安全 `sync_error`；页面显示等待上线、同步中、已确认、失败和重试入口。目标未完成时可编辑草稿、应用新草稿、核对引擎及启停；启停串行执行，并把新的运行意愿写入后续目标，不因同步失败阻止用户停止引擎。升级/卸载等操作须先处理未完成目标。同期已获授权的停止操作会被后续目标保留。
- 保存者必须有全部引用节点的管理权限，包括仅草稿引用；单次最多 500 个引用引擎，超过上限明确拒绝，不截断影响范围。

TLS、XHTTP、WebSocket、本节点站点和非 Chrome 指纹可以保存为预设，但不能引用到现有节点执行链路。自动证书、分组和创建后立即部署尚未接入；多 Short ID 通过 `engine.manage.v2` 能力协商，任务字段为 `short_ids` 数组；Panel 与独立 Agent 需使用匹配协议。仅声明旧 `engine.manage.v1` 的 Agent 不接收新引擎任务，不做单值回退。

## API 与存储

- `GET /api/v1/protocol-presets`：viewer 及以上可读；`limit` 默认 50、最大 100，`after` 使用响应中的 `next_cursor`，按 ID 升序。满页可能返回游标，最后一次查询可为空。拒绝未知或重复查询参数。
- 创建和列表响应新增 `reference_issues`：按 `sing-box`、`xray`、`realm` 返回当前执行适配器的禁用原因，空字符串表示可引用。下拉框保留不兼容项并禁用；sing-box 的 XHTTP 标注引擎不支持，Xray 标注当前执行链路未接入，不能混淆引擎能力与本项目交付状态。前端遇到未知引擎或缺失兼容性信息时禁用选择，保存草稿继续由服务端校验。
- `POST /api/v1/protocol-presets`：operator / admin 可创建，要求会话、CSRF 和 Origin。成功返回 201；非法参数 400，名称冲突 409。
- `GET /api/v1/protocol-presets/{id}`：读取当前内容与并发摘要。
- `POST /api/v1/protocol-presets/{id}/preview`：operator/admin，接收 `config`、`base_digest`，返回影响范围与确认凭据。
- `PUT /api/v1/protocol-presets/{id}`：operator/admin，接收相同配置、摘要及 `confirmation`，再次校验后原子保存；200 表示保存成功，不表示节点已生效。
- `POST /api/v1/engines/{id}/sync`：具备节点管理权限的 operator/admin 重试最新目标；204 表示已请求。离线不创建任务，unknown/degraded 须先核对恢复。
- 上述写接口均校验会话、CSRF 和 Origin。冲突/过期确认 409，参数错误 400，无权访问 403，不存在 404。
- 迁移 `0012_engine_targets` 保存加密的完整引擎目标、凭证快照、非敏感引用快照及同步错误；开发期不转换旧快照引用或反推覆盖值。
- 迁移 `0011_protocol_presets` 新增表，配置为非敏感 JSON；名称唯一约束及创建审计在事务内提交。普通列表不包含服务凭证。
- 资源为实例共享预设，节点使用权限仍由既有节点级授权控制。OpenAPI 从路由及 Go 类型生成。
