# 引擎与服务开发验收记录

更新：2026-11-03。内部开发测试阶段；本次直接更新初始 Schema，不维护历史数据库兼容性。使用新的开发数据库，不自动删除或改写已有数据库。

## 已实现的核心流程

- 节点详情的引擎页提供 sing-box、Xray、Realm 安装、共享草稿、服务编辑、应用、启停、核对、恢复上一成功配置、凭证更换、卸载和连接二维码。安装不自动启动；保存草稿不提交任务。离线可编辑，执行操作由服务端拒绝。
- 服务端逐节点授权，安装/升级/卸载限管理员；操作和凭证导出分别授权。管理员通过 `PUT /api/v1/nodes/{id}/engine-access` 配置权限。所有接口以生成的 OpenAPI 为准。
- 草稿使用条件版本更新。不可变提交快照、加密任务参数、期望修订及审计同事务保存；同引擎变更互斥。修订编号同时包含配置和生命周期操作；核对只更新运行状态，不把未知配置标记为已应用。
- 禁用服务保留端口；待删除服务成功应用后清理。提交后继续编辑的草稿不会被完成回报覆盖。未确认的配置快照继续保留端口，防止未知副作用造成重复分配。
- UUID 和 REALITY 私钥使用 AES-GCM 存储。普通 DTO、任务查询和 SSE 不含完整配置或私钥；连接导出单独鉴权并审计。恢复历史配置使用当前有效凭证，不复活已更换凭证。
- Agent 仅在 Linux、systemd、root、amd64/arm64 下声明 `engine.manage.v2`。固定版本、发行地址和 SHA-256；禁止任意 URL、Shell 和自动接管第三方实例。
- Agent 执行记录先于副作用持久化。重投返回已保存结果；中断记录返回结果未知，不能盲目重执行。关联校验涵盖节点、任务、attempt、资源、命令摘要和修订。
- 本地监听/目标预检、原子配置切换、systemd 启停和有界回滚。停止意愿通过 disable/stop 保存；停止时应用不启动。Realm 使用结构化校验，没有伪造不存在的 `--test` 参数。外部连通始终标记未验证。

## 开发版本清单

`api/agent/v1/engine-releases.json` 固定 sing-box 1.14.4、Xray 26.10.31、Realm 2.9.6 的 Linux amd64/arm64 官方发行资源及摘要。这是开发适配清单，**不是经过实机验收的生产兼容清单**。目前每种引擎仅一个版本，升级执行与回滚路径已编写，但没有可选择的新版本，也未完成真实升级验收。

## 验证与限制

本地验证覆盖真实临时 SQLite 的并发草稿、事务、权限、端口、快照、凭证轮换/恢复和 HTTP 状态；Agent 测试使用临时文件、真实本地监听及模拟 systemd 管理器，覆盖停止意愿、所有权、幂等执行和配置生成。通过这些测试不能证明实际引擎兼容。

浏览器使用隔离测试数据库验证了离线草稿编辑/保存、执行禁用、Toast 和弹层焦点返回，以及 390/768/1024/1440px 和浅/深主题布局。隔离节点不是真实 Agent，不能作为部署成功证据。

Web 全量测试有一项已有失败：`src/api/telemetry.test.ts` 的 600 条样本断言实际得到 120；在未修改的 HEAD 归档中复现。本次不修改无关遥测逻辑。

## 数据、密钥与协议维护

数据库旁的 `<database-path>.engine-key` 为 32 字节私有密钥，要求普通文件及 0600 权限。数据库和密钥必须配套备份并分开控制访问；已有加密操作而密钥丢失时启动拒绝自动生成替代密钥。不得提交密钥或开发数据库。

协议唯一源为 `api/agent/v1/envelope.schema.json`，运行 `python3 scripts/generate_protocol.py` 生成模型；使用 `python3 scripts/sync_engine_protocol.py --check` 检查相邻 Agent 仓库的协议辅助代码、Schema 和发行清单一致。HTTP 契约运行 `make generate-openapi` 生成，禁止手改生成文件。

## 2026-11-04 引擎页交互重构

- `/nodes/:id?tab=engines` 按引擎选择器、运行时信息、草稿发布栏、服务表格组织。切换 sing-box、Xray、Realm 保留各引擎本地修改；刷新共享草稿时不覆盖未保存内容。
- 表格提供草稿启用开关、监听/目标/SNI/公网入口、编辑、标记删除与撤销。更多操作保留核对、恢复、Realm 目标风险应用和卸载；服务凭证更换仍会应用整个已保存草稿，确认文案明确影响范围。
- 连接弹窗支持全部或单服务读取，显示已应用修订、二维码和复制链接。读取失败不替换页面；复制成功仅在剪贴板写入完成后提示。未登记公网入口也能从服务操作发起凭证更换。
- REST/Agent 契约不变。草稿版本与配置修订不是同一计数器，界面不依据二者大小宣称草稿已发布或全部同步。
- 验证：Web typecheck、build、改动文件 Biome 与 diff 检查；全量 Web 测试 212 项通过，1 项既有遥测样本数量断言失败（600 与 120），与上述已知问题一致。
- 浏览器使用临时隔离测试数据验证切换保留草稿、离线执行禁用、保存成功、保存失败 Toast 与输入保留、抽屉焦点返回、服务删除/撤销；检查 390/768/1024/1440px、浅色中性及深色蓝色主题，页面无横向溢出。测试夹具未加入产品或提交。未执行真实 Agent 安装、应用、凭证轮换与外部客户端测试；这些仍属于前述实机验收缺口。
